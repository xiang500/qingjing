# 轻境 · 四季光场设计系统

> 关键词：四季、服装、液态玻璃、编辑感排版。
> 这份文档解释「为什么长这样」以及「怎么改」，方便答辩时讲设计取舍。

## 1. 概念：不是一套深色主题，而是四束光

衣橱本来就和季节绑在一起：换季、叠穿、收纳。所以界面不固定成"暗金风"，而是让**季节决定光线**：

| 季节 | 光线 | 气质 | 主色 | 明暗 |
| --- | --- | --- | --- | --- |
| 春 | 晨光 | 新绿、樱粉、雾蓝 | `#5f7f58` 柳芽绿 | 浅色纸感 |
| 夏 | 正午 | 海盐、细沙、薄荷 | `#2f7c88` 海盐蓝 | 浅色纸感 |
| 秋 | 暖阳 | 杏黄、焦糖、苔绿 | `#b06526` 焦糖橙 | 浅色纸感 |
| 冬 | 夜雪 | 冰蓝、雾紫、烟灰 | `#a9c9e2` 冰蓝 | 深色夜色 |

季节现在是**自动轮播**的：页面打开时按当前月份起步（11 月 → 秋），之后每 30 秒自动换到下一季（春 → 夏 → 秋 → 冬），导航右侧只有一条进度线提示"还有多久换季"，不需要任何按钮。换季时用 View Transition 做整页交叉淡入，浏览器不支持就直接换色。春 / 夏 / 秋都是浅色纸面（绿 → 青 → 杏黄，靠色相区分），只有冬季转深色夜色；页面里的玻璃卡片会把背景的季节色晕折射出来——**背景、材质、文案是一套的**，而不是给页面贴一张壁纸。

> 秋季最初做成了深褐"暮色"，但深底 + 焦糖 accent 整体过暗、层次糊在一起，实测后改成**杏黄浅色（秋·暖阳）**：底色 `#f8efdf`，accent 换深焦糖 `#b06526` 以保证浅底上的对比度。

## 2. 液态玻璃（Liquid Glass）怎么实现

参考的是 B 站「纯 CSS 高仿苹果液态玻璃」的做法（BV1J8QSBqEpy），在 `src/style.css` 里落地成三个原语：`.glass`、`.glass-soft`、`.photo-tile`。

一层玻璃 = 五个细节叠加：

1. **玻璃底**：`linear-gradient(148deg, 白 10%, 白 3.5%)` 半透明底 + `backdrop-filter: blur(26px) saturate(180%) contrast(106%)`，背景色晕透过来就有了"折射感"。
2. **双层折射边框**：`::before` 用 `mask-composite: exclude` 只留 1px 描边，渐变让左上角亮、右下角弱——模拟玻璃边缘的厚度和反光。
3. **顶部高光**：`::after` 一层从顶部往下的白色径向柔光，玻璃靠近光源的那一侧更亮。
4. **内阴影**：`inset 0 1px 0 白 90%` + `inset 0 -1px 0 白 34%`，让上边缘像被光照亮、下边缘收到暗部。
5. **外阴影**：很淡的一层，在浅色背景上也能把卡片从背景里"抬起来"。

深色季节单独降低白色比例、加深外阴影，避免玻璃在夜里反光过曝。

> 性能取舍：`backdrop-filter` 会触发一次背景采样，所以全站只在导航、卡片、弹窗这类"大面"上使用；列表项用更轻的 `.glass-soft`（blur 18px），并且没有堆叠多层半透明面板。

## 3. 排版与页面骨架

### 3.1 布局标度：间距与圆角只允许固定值

所有页面共用两套标度，写在 `style.css` 的 `:root` 里，**不允许再出现随手写的任意值**（如 `0.55rem`、`rounded-[1.35rem]`）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--space-1` … `--space-8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px | 组内元素用小档，区块之间用 `--space-7` |
| `--radius-xs` | 8px | 小标签、色块 |
| `--radius-sm` | 12px | 输入框、缩略图 |
| `--radius-md` | 16px | 卡片内层、按钮组（`.glass-soft`） |
| `--radius-lg` | 24px | 玻璃面板（`.glass`） |
| `--radius-pill` | 999px | 胶囊按钮、筛选 |

### 3.2 页面节奏：拆块 → 组间留白 → 依次错开

每个页面都按同一套骨架组织，不再把内容一长条平铺下来：

1. **页面根**用 `.page-stack`：区块之间自动 48px（手机 32px）。
2. **每个区块**用 `.section-block`（内部 24px），头部用 `.section-head`：左边 eyebrow + 标题 + 一句说明，右边操作区，自动换行。
3. **操作靠明暗对比推出来**：主操作 `.btn-primary`（亮底），次操作放在 `.action-row` 里会被自动压暗（`--c-bg` 混底 + 更弱的描边）。页面上不允许处处都是亮按钮。
4. **次要信息下沉**：说明、隐私、技术细节放进 `.surface-sunken`（比玻璃暗一档），不抢主视觉。
5. **同级几块依次错开**：用 `.staggered`，桌面端偶数块下沉 16px、最后一格补回，形成"阶梯"节奏；手机端自动取消，避免无意义空白。

这三条对应的正是评审反馈里的"内容组织"和"加载体验"之外的第三个问题：**版面没有节奏，所有东西一样重**。

### 3.3 其它排版约定

- **标题**：`Songti SC / Noto Serif SC` 衬线（`.display`），字号 `clamp(2.3rem, 4.5vw, 3.8rem)`，两行断句；第二行用季节 accent 色，形成"杂志封面"的重音。
- **小标**：`.eyebrow`，10px、`letter-spacing: .38em`、大写，前面带一条短横线，用于 `AUTUMN · 暖阳 · 霜降` 这样的季节信息。
- **正文**：14px / 行高 1.9，宽度限制在 34rem 左右，避免长行难读。
- **留白**：首屏两栏（宣言 + 本季卡）、画廊、数据条、AI 套装、筛选、单品网格，节奏是"大块玻璃 → 小卡 → 数据"。
- **单品图**：统一放在 `.photo-tile` 深色"影棚底"上（`#101216` + 顶部柔光）。原因是插画/照片本身是深色的，浅色季如果直接放白底会糊成一片；固定影棚底让四季都有一致的商品质感，也像品牌 lookbook 的产品图。

## 4. 季节背景是纯 CSS

`src/components/SeasonBackdrop.vue`，零图片、零第三方库：

- **三层色晕**：3 个 `blur(72px)` 的大圆，用季节主色，48~66 秒缓慢漂移，让玻璃后面的颜色"活"起来。
- **季节动机**：春·花瓣（12 片粉白圆角片缓缓落下）、夏·光尘（向上浮的金色微尘 + 顶部光锥）、秋·落叶（焦糖斜片翻落）、冬·雪（小白点慢速落下）。
- **颗粒**：一层 `feTurbulence` SVG 噪点，`mix-blend-mode: overlay`，消除大面积渐变的色带。
- **暗角**：径向渐变压暗四周，把视线收回中间。

性能与无障碍：粒子全部 `transform` 动画、数量 ≤14；`prefers-reduced-motion: reduce` 时动画时长归零；背景元素 `aria-hidden` + `pointer-events: none`。

## 5. 色令牌与组件原语

所有颜色都在 `style.css` 的 `html[data-season]` 块里定义成 `--c-*` 变量，Tailwind 的语义色（`ink / mist / gold`）再映射到这些变量：

| 令牌 | 用途 |
| --- | --- |
| `--c-bg / --c-bg-2 / --c-bg-3 / --c-bg-4` | 页面底、面板底、浮层底 |
| `--c-ink / --c-ink-2 / --c-ink-3` | 主文字 / 次文字 / 三级文字 |
| `--c-muted / --c-muted-2` | 说明文字、占位符 |
| `--c-line / --c-line-soft / --c-line-strong` | 描边与分隔线 |
| `--c-accent / --c-accent-strong / --c-accent-soft / --c-accent-ink` | 强调色及按钮文字 |
| `--c-glass-a / --c-glass-b / --c-glass-edge / --c-glass-shadow` | 玻璃材质 |
| `--c-wash-1..3` | 背景色晕 |

组件类：`.glass`、`.glass-soft`、`.photo-tile`、`.btn-primary`、`.btn-ghost`、`.chip`、`.chip-active`、`.field-input`、`.field-label`、`.display`、`.eyebrow`、`.on-photo`、`.skeleton`。

换季时只改 `<html data-season>` 与 `<html data-scheme>` 两个属性，整站换色；Element Plus 通过 `html.dark` 类同步深浅。

## 6. 怎么改

- **换季色调**：改 `style.css` 里对应 `html[data-season='…']` 的 `--c-*`，同时更新 `src/theme/seasons.ts` 的 `swatches/bgHex`。
- **加一个季节**：在 `seasons.ts` 增加 meta，在 `style.css` 增加色盘，自动轮播会按 `SEASON_AUTOPLAY_MS` 的节奏把新季节纳入循环（循环顺序定义在 `stores/theme.ts` 的 `CYCLE`）。
- **加玻璃面板**：给容器加 `class="glass"` 即可；小卡片用 `glass-soft`。
- **加按钮**：`btn-primary`（主）/ `btn-ghost`（次）；不要新写渐变。
- **放图**：外层 `.photo-tile`，内部 `img` 自动 `object-fit: contain`；图上的文字用 `.on-photo`。
